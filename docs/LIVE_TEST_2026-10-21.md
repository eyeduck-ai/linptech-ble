# Initial advertisement tests: 2026-10-21

Historical Windows local-BLE sessions authenticated advertisements from all four configured models. Keys were supplied privately and are not in this repository.

- MS1BB: opening/closing and battery.
- KS2BB: press, double-press, long-press and humidity.
- HS3BB: motion, illuminance and no-motion duration; model-scoped support was added without patching installed xiaomi-ble files.
- ES5BB: illuminance and unoccupied state after local wake.

ES5 occupied state and KS2 temperature updates were confirmed in the [next session](LIVE_TEST_2026-10-22.md). These records establish specific received fields, not full validation of every feature. Current support is in [device capabilities](DEVICE_CAPABILITIES.md).
